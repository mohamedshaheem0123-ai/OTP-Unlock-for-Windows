## 📌 Overview

The **OTP-Based Secure Authentication System** is a Python-based authentication project designed to provide an additional layer of security beyond traditional username and password authentication.

The system uses **FastAPI** as the backend framework and supports **Authenticator-based Time-Based One-Time Password (TOTP)** authentication.

Instead of relying only on a password, users can authenticate using a temporary six-digit OTP generated by an authenticator application.

This approach helps reduce the risk associated with password-only authentication and demonstrates the practical implementation of **Two-Factor Authentication (2FA)**.

# 🎯 Project Objectives

The main objectives of this project are:

- 🔐 Implement secure user authentication
- 🛡️ Add an additional OTP-based security layer
- 📱 Integrate Authenticator-based TOTP verification
- 🔑 Provide secure password-based login
- 🔄 Provide password recovery functionality
- 🗄️ Store application data using SQLite
- 🔒 Protect sensitive information using encryption
- ⚡ Build a lightweight authentication backend using FastAPI
- 🧪 Provide API endpoints that can be tested using Swagger UI
- 🎓 Demonstrate practical cybersecurity and authentication concepts
